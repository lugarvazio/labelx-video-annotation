# LabelX — разметка видео (прототип)

Интерактивный прототип рабочей области разметки видео: рамки, треки объектов, ключевые кадры с интерполяцией, «вне кадра», таймлайн треков.

**Открыть:** https://lugarvazio.github.io/labelx-video-annotation/

Версии переключаются в левом сайдбаре; прямые ссылки — `#v1` … `#v4`.

Обновление: правки вносятся в `../video-annotation.html`, затем `./build.sh` и коммит `index.html`.
